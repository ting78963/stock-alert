# D5 F10 門檻搜尋（隔離研究）

程式：`d5_f10_threshold_search_20261017.py`，僅 Python 標準函式庫。
不匯入正式模組、不連行情 API、不使用 FinMind、不啟動排程。

## Render Shell

先以已確認的交易日資料準備 `/tmp/d5_sessions_20261001_20261016.json`：
JSON 格式為 `{"source":"可核對的交易日清單來源","sessions":["YYYY-MM-DD", "..."]}`。
必須列出 2026-10-01～2026-10-16 的所有實際交易日（不要直接列平日，
也不要用 F10 有資料的日期反推完整交易日）。無此清單不能解讀日期覆蓋。
程式只驗證清單格式，無法驗證提供者引用的來源是否正確。

在研究分支 checkout 中執行（不需要部署正式服務）：

```bash
python -B research/d5_f10_threshold_search_20261017.py --self-test
python -B research/d5_f10_threshold_search_20261017.py \
  --db /var/data/stock-alert/f10_baseline_v1.sqlite3 \
  --mother /var/data/stock-alert/a_scan_mother/2026-10-16/stock_ids.json \
  --sessions /tmp/d5_sessions_20261001_20261016.json \
  --out /tmp/d5_f10_search_run_01
```

輸出必須是不存在的新目錄，不能放在 `/var/data`；重跑需換新名稱。
SQLite 使用 mode=ro、query_only 與同一讀取交易，沒有 DDL、UPDATE、checkpoint。
有資料品質阻擋時退出碼為 2。查核輸出不代表正式資料曾被修改。

## 方法與輸出

- 訓練窗口固定 10/01～10/15；最後兩個已確認交易日作訓練期內 holdout，
  更早日期產生候選。少於四個訓練交易日即停止。
- 取較早訓練樣本 09:10 累積量的經驗分位數，組合兩種時段網格與遞減分位數。
  張數由資料產生，不預設 1700、1400 等數值；去重後至多 18 組。
  這是有限搜尋空間，沒有宣稱涵蓋所有可能門檻。
- 用訓練 holdout 的 M+1 模型找 Pareto shortlist：較多提前至少10分鐘，
  較少延後/失去資格、額外候選、單分鐘新達標尖峰。
  未給真實訊號品質與容量預算，因此不指定單一最佳解。
- 凍結候選、訓練資料指紋與 shortlist 後評估 10/16；不因驗證成績重新挑選。
- 全部 F10 = 此次 member 表（排除4906），不等於歷史全市場；訓練與驗證使用同一集合。
  10/16 A母清單只作當日獨立分組，不用它挑選訓練門檻。
- 每分鐘檢查門檻。標籤模型使用截至該分鐘量；M+1 使用前一分鐘累積量，
  至13:30停止，不使用13:30未完成棒。兩者均不是API真實抵達時間。
- 每股票日要求09:00～13:30全部分鐘有明確累積量；不補零、不延續缺棒，
  不以後來的資料倒推缺棒。缺少交易日/股票日/分鐘會阻擋相關群組。
  訓練群組不完整停止全部搜尋；10/16群組不完整僅阻擋該群組驗證。
  嚴格策略可能因處置股間隔成交而無法比較，不能為了產生結果而放寬。
- F10原產生器可能將空volume轉零，且只留最近11個有效交易日。
  此工具不能證明原始來源無遺漏、單位或當時可用性；輸出僅是已存封存量的條件比較。
  不能把完整時鐘網格當成已驗證真實逐筆成交。

輸出：

1. `report.json`：來源資料列/member/母清單/交易日SHA256、缺漏明細、群組阻擋狀態、
   候選凍結指紋、模型統計、各日尖峰時間、新候選與OLD的每分鐘到達數、效果股票清單。
2. `candidates.csv`：各候選ID、完整時段門檻、訓練shortlist標記。
3. `comparison.csv`：OLD與所有候選在FIT、TRAIN_HOLDOUT、TRAIN_ALL及可驗證10/16群組的比較。
   每種時間模型各一列；阻擋時不造數字。

提前5/10/20為累積條件（>=），不是互斥桶。same/earlier/delayed/extra/lost/neither
才是互斥股票日分類。CSV的效果數為股票日數；JSON另有不重複股票數及股票代號。
中位數僅配對雙方皆達標樣本，含0分鐘；額外/失去資格不填0。
尖峰指同一交易日、同一分鐘首次達量的股票數，不是API呼叫數或B處理量。

後續先確認真實資料覆蓋，再以預先定義的B容量上限與訊號品質指標選擇少數候選，
用後續未見交易日驗證。10/16已看過的結果不得用來反覆調整後再自稱獨立驗證。
